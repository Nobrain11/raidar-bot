# Raidar Bot

Full-featured Telegram bot for X/Twitter raid groups.

## Features
- Raid management
- Queue system
- XP & Leaderboard
- Rewards

## Setup
1. Install dependencies: `pip install python-telegram-bot==20.8`
2. Run: `python raidar_bot.py`

**Note**: Change BOT_TOKEN and ADMIN_IDS in production.
